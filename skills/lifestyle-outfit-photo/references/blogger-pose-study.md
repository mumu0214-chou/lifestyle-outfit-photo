# 博主封面姿势拆解

以下案例从穿搭作品封面提炼可迁移的姿势关系。单张封面只能说明画面中的姿态，动作前后过程、被遮挡的支撑点、面部细节和精确机位保留为不确定。

这份资料用于姿势分析和方案选择。实际生图输入按本次脸图、商品图和用户指定的其他参考准备。需要复现特定姿势时，使用用户本次提供的清晰单张图，并按指定用途提取动作和角度。

## 具体画面与可迁移关系

| 示例场景 | 可见的姿态关系 | 迁移到新照片时怎样使用 |
|---|---|---|
| 街头浅色外套与黑帽 | 头低下，一手抬到帽檐或眼旁，另一侧手臂低位持物，双臂高度不同 | 用触帽、遮光或整理头发形成上方动作，另一只手安排合适的包或自然下垂。手腕、肩线与遮脸范围协调，外套主体保持可读 |
| 棕色外套坐椅自拍 | 坐姿、屈腿、上身略前倾，持手机的手与身体转向共同组织画面 | 根据实际椅面和镜子安排座面支撑、腿部空间及手机位置。截图中的部分接触点受遮挡，应为新场景明确可成立的支撑 |
| 浅色长外套与树荫道路 | 身体偏侧向，头部向上方偏转，双臂保持较低位置 | 将侧身与抬眼或转头组合，控制头颈幅度。适合已有侧面依据的衣服轮廓，取景留出头部朝向的空间 |
| 黑上衣与浅色长裙背影 | 背身略侧，头部朝一侧，包在身体后侧形成层次 | 有背面商品依据时用背侧姿态交代衣服与裙摆。同组可另配正面图完成正面结构展示，包的位置按实际肩带与重量表现 |
| 灰上衣、短裙与横栏 | 身体斜向靠近横栏，头转向一侧，一手低垂，腿部向画面一侧延伸 | 借横栏与身体形成斜向关系。封面难以确定栏杆承担的重量，新场景按栏杆高度选择轻靠或稳定站姿，明确脚下支撑 |
| 黑上衣、米色长裤 | 一张双手低位持物、双腿较收拢，另一张上身略倾、一腿向侧前方伸出、持物手低垂 | 同一套衣服可用收拢站姿交代整体，再用展开的腿部关系与身体倾斜增加变化。伸腿姿态既可来自摆姿，也可来自迈步，生成时选定一种可成立的阶段 |
| 黑裙坐台沿 | 身体坐在台沿，一手撑台，头看向侧方，裙摆铺在座面上 | 使用真实可坐的台面，按座面高度安排腿脚和衣摆。一只手支撑、另一只手放松，形成清楚的身体与环境接触 |
| 车厢内黑上衣与花裙 | 一手抬起握竖杆，另一手靠近腰部，头略低，两侧手肘形成不同角度 | 在有竖向支撑物的场景采用高低手位，头部与注意目标对应。按真实接触处理握杆手，低位手避开需要展示的裙腰或图案 |
| 街头扶栏 | 手臂向侧后方伸展触栏，躯干与栏杆有距离，腿部呈错位或屈膝关系，头朝侧方 | 按栏杆位置确定手臂伸展与身体距离，用合理的支撑腿和放松腿形成变化。可用另一手拨发、持物或低垂，按本张商品目标选择 |
| 树林黑衣及夜景柱边 | 手在帽子或头部附近形成遮挡，身体有倾斜，双脚位置交错或前后错开 | 在可执行的脚下支撑基础上组合触帽与遮脸，利用场景里的路径或柱边组织画面。仅在实际接触时表现倚靠受力 |
| 白上衣镜前自拍 | 一手持手机遮住部分脸，另一手横向抬到额头附近，腰胯与肩部略有方向差 | 手机承担拍摄，空闲手承担拨发或遮挡，两只手各自可执行。按用户要求确定遮脸范围，保持镜面关系和上衣关键结构可读 |
| 车后座看手机 | 身体靠在座椅中，头向手机低下，双手围绕手机，衣服与裙料覆盖腿部 | 在有靠背的场景用座椅支撑和手边任务表现松弛。服装体积、靠背挤压与裙料堆叠随姿态变化，适合半身或生活状态展示 |

## 从封面提炼组合方法

- **让头身朝向有分工。** 侧身可配侧看、抬眼或看向镜头，背身可保留侧向头部，头与身体在合理活动范围内形成差别。
- **双手各有位置和任务。** 一手在帽檐或头侧、另一手低位持物，一手接触支撑物、另一手靠近腰部，都会改变轮廓和遮挡。选适合商品的关系，手部姿态服从接触与受力。
- **利用支撑改变整个身体。** 椅面、台沿、靠背和栏杆分别允许坐、侧坐、靠坐或轻靠。支撑改变后，骨盆、肩线、腿脚与衣料一起响应。
- **安排收拢与展开的变化。** 双腿较收拢与向前侧伸腿、手臂贴近身体与抬起触帽，可在同组形成轮廓差异。幅度由鞋型、服装和场景空间决定。
- **把姿势放进构图。** 栏杆可与伸展手臂呼应，墙面留白可以容纳伸腿和身体倾斜，侧身视线可朝向画面留出的空间。人物占比与拍摄距离根据商品信息安排。
- **让表情变化服从这类拍照气质。** 这些封面中有多张低头、侧看、背身或遮脸画面，可借头部方向与身体状态形成变化。可见的部分表情幅度较小，细微眼口变化需要清晰单张图进一步判断。

## 迁移与验收

先选与当前商品和场所相容的一种身体关系，再确定支撑、双手、头部方向及取景。沿用本次模特的脸与已约定的身形，让服装在新姿态下自然受力。商品缺少背面依据时选用有依据的侧正面关系，展示领口或袖型时相应调整手臂遮挡。参考里的帽子、包和露肩效果按本次搭配与商品结构决定。

生成后核对所选的关系是否实际出现，例如扶栏手是否接触栏杆、侧坐是否有座面支撑、头部与身体朝向是否可辨、双腿错位是否仍有合理承重、遮脸是否符合指定范围。同时检查本张商品重点是否清楚。以真实可见的姿态差异判断学习效果。
