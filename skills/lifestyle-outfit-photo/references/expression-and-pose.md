# 表情与姿势设计

先确定照片要呈现的人物状态和商品信息，再选择表情、身体动作与拍摄时机。以下示例用于拓展选择，按人物、穿搭、场所和用户偏好重新组织。用户指定的姿势、表情或连续动作优先。

## 把表情落实为可见表现

身份参考提供人物特征。每张图根据当前状态决定眼睑开合、脸颊变化和嘴部形态，让同一人物具有自然的表情活动。正面静态脸图也可用于设计其他表情，表情幅度和视角越大，越需要仔细核对个人特征。

设计时回答人物在注意什么、受到什么影响，以及照片停在反应的哪个阶段。对镜头摆姿本身就是成立的拍摄情境，姿态的松弛或时尚表现力按用户风格选择。选择最能让观众读懂状态的少量细节，避免把脸部各处都写成用力表演。近景可细化眼口配合，全身景优先让头部、视线与整体姿态传达状态。

| 人物状态 | 可采用的可见表现 | 与动作、取景的联系 |
|---|---|---|
| 平静、自信地面对镜头 | 目光有焦点，眉间舒展，嘴唇自然合拢或放松，肩颈松弛 | 正面或略侧身站立、坐姿均可，头部角度配合镜头位置 |
| 克制、清冷或略有距离感 | 表情幅度较小，嘴角中性，视线可直视或略过镜头，头颈保持舒展 | 可配合侧身、简洁站姿或靠坐，用视线与构图表达气质 |
| 专心听朋友说话 | 视线落在镜头旁的交谈对象，头部略转，嘴部处在聆听的放松状态 | 身体仍可朝前或继续手边的小动作，头与身体转向有自然差别 |
| 刚开始微笑 | 目光转向引发反应的人或事，嘴角刚抬起，脸颊与眼周随幅度轻微变化 | 适合回看、打招呼、整理衣服时被叫住的瞬间 |
| 明显开心或笑开 | 嘴部开合、脸颊抬升和眼睑变化协调，肩颈随反应放松 | 适合真实的交流或动作间隙，取景留出头部和身体反应的余量 |
| 专注于手边事物 | 视线有具体落点，眉眼与任务强度相符，嘴部保持自然 | 整理袖口、查看物件或调整坐姿，面部角度与手边目标对应 |
| 听见招呼后回头 | 视线与头部刚转向声音方向，表情可处在辨认或回应的过渡 | 肩、躯干和脚的转动进度合理，捕捉可支撑的停步或回身阶段 |
| 轻松、略带俏皮 | 一个有依据的轻微挑眉、短暂偏头或抿笑，幅度服从人物与情境 | 适合熟悉的人互动或用户指定的风格，选择能读懂的主表情 |
| 动作结束后的松弛 | 呼吸和嘴部自然，视线稍离镜头，肩膀放松 | 坐下、放好物件或走到目的地之后，可形成安静的生活片刻 |

这些状态可组合或扩展。冷淡、克制、笑开等方向按用户审美与人物状态选择，整组的变化可来自视线、强弱或反应阶段。笑容应随个人特征与幅度变化，避免把每个人都处理成相同的眼形和嘴角。光线引起的眯眼与情绪变化分别按原因表现。

例如，把“自然甜美”具体化为“听见镜头旁朋友叫她，视线刚转过去，嘴角刚抬起，肩膀仍放松”。如果人物正在专注检查袖口，则让视线和头部跟随袖口，嘴部采用符合专注状态的放松表现。

## 从身体支撑拓展姿势

先选身体如何支撑、朝向哪里和动作处于什么阶段，再安排头部与双手。动作需要的墙、椅子、台阶或物件应在场景中成立。服装的活动范围、鞋型和展示部位决定动作幅度。

| 姿势方向 | 可发展的动作 | 商品与身体关系 |
|---|---|---|
| 自然站立 | 双脚自然落地、轻微重心交换、一步前后站、身体略侧 | 适合交代整体版型，肩胯与支撑脚协调，手部给门襟和腰线留空间 |
| 侧身与回身 | 侧站看向镜头、转头回应、躯干回转到一半 | 适合有依据的侧面轮廓或背部细节，头颈与肩胯转动幅度协调 |
| 走动与停步 | 跨出小步、刚落脚、走到镜头前停下、转弯后回看 | 用落脚、摆臂和衣摆共同体现阶段，服装和鞋型允许步幅 |
| 坐姿 | 自然坐在椅上、靠近椅边、稍侧坐、坐着转向交谈对象 | 骨盆有支撑，膝脚位置合理，衣摆与座面接触和垂落可信 |
| 倚靠 | 轻靠墙、前臂扶栏、手扶桌沿、背靠长椅 | 区分轻触与承重，让接触点和身体倾斜匹配，并保留商品重点 |
| 落座与起身 | 手轻扶椅沿准备坐下、刚坐稳、从椅上起身的一刻 | 用骨盆、膝脚与支撑手说明动作阶段，控制衣料的受力和遮挡 |
| 台阶与高差 | 站在台阶上、跨上一级、停步调整方向 | 场景确有可用台阶时采用，核对双脚高度、支撑与重心 |
| 整理穿着 | 理袖口、整理外套下摆、调整肩带、拨开遮住领口的头发 | 手的任务服务于商品展示，触碰与拉动有对应衣料反应 |
| 拿放物件 | 放下杯子、取出手机、打开书、把包放到身旁 | 选与场所相关且不抢商品的动作，手指接触、物件重量与视线有依据 |
| 交流与回应 | 向朋友侧身、轻抬手回应、听人说话时转头、回身招呼 | 根据交谈对象安排视线和身体方向，手势幅度符合人物状态 |
| 镜前自拍 | 正面或侧身照镜、改变站位、坐着自拍、手机遮脸时调整空闲手 | 手机握持、镜面反射和遮挡范围共同成立，按展示目标安排构图 |
| 近景或半身 | 正视、略转头、回看镜头旁、坐着轻转上身 | 用头颈、肩线和视线变化组织画面，突出领口、面料或配饰细节 |

同一姿势方向也能产生不同画面，差别可来自身体朝向、支撑关系、动作阶段或拍摄距离。比如站姿可分别承担正面看版型、侧身看轮廓和停步看衣摆。坐姿会遮住部分衣长，若本图要展示完整下摆，应调整取景或选择更适合的动作。

身体主姿态确定后，再组合有依据的手臂位置。可以自然垂手、轻搭手腕、单手扶腰、轻抱臂、手搭头侧、拨发、扶椅沿或坐姿托腮，商品确有口袋时可插袋。按领口、腰线、袖型等展示重点安排遮挡与接触，让身体和双手共同形成完整姿态。手臂变化可以丰富同一姿势，整组的主差异仍结合支撑、朝向和取景判断。

用户提供的博主封面中，可迁移的组合包括抬手触帽与低位持包、侧身配合另一个头部朝向、借椅沿或栏杆形成支撑、收拢站姿与伸腿姿态交替。头、肩、胯和脚可以有自然的方向差，双手也可以各有任务。先让这些关系可执行，再按商品展示目标控制遮挡。具体可见证据和迁移边界见[博主封面姿势拆解](blogger-pose-study.md)。

## 让组图产生有效变化

生成前简要比较每张的展示目的、支撑与动作、视线和表情、景别与角度。保留本组约定的一致性，让各张拥有可辨的主变化，其余细节围绕它协调。张数多时，从服装、场景和人物状态继续推导动作，按任务选择示例范围之外的变化。

例如同一套穿搭可由正面站姿交代版型，走停之间表现垂感，坐姿侧看表现生活状态，半身整理袖口展示细节。需要展示完整衣长的任务，可以保留多张站姿，通过朝向、步态和取景形成差别。用户要求连续动作、统一冷淡表情或相同机位时，围绕这些要求安排变化。

一组可以保持克制的表情，通过低头、侧看、抬眼或遮脸形成变化。主动摆姿可直接成立，表情和生活事件的安排服从用户选择的拍照气质。姿势参考被衣服或画面边缘挡住的部分，迁移时选取合理支撑，并保留对原图实际动作的判断边界。

生成后查看实际画面。若动作描述不同但成图仍是相同站姿，调整支撑、身体朝向或镜头关系。若整组出现同一笑脸，先检查视线目标和反应阶段，再调整合适的表情强弱。完全遮脸时，变化由头部方向、身体姿态和手部任务承担。

## 根据失败画面修正

- 嘴角在笑而目光涣散时，先明确注意目标，协调眼睑、脸颊与嘴部的幅度。局部编辑以原始脸图维持身份。
- 笑容一变化就不像原人物时，对照原脸的可辨特征与当前角度，检查脸型、眼鼻、唇部和发际线是否出现无依据的改变。必要时降低本次表情幅度，或使用同一人物更接近目标表情的参考。
- 表情过于用力时，选择更轻的反应阶段，放松眉间、嘴部或肩颈中实际紧张的部分。表情变化应能与当下动作共同成立。
- 姿势僵硬时，先核对重心、接触和动作目的，再调整局部关节。清楚的支撑与轻微的自然不对称通常比堆叠手势更易形成可信动作。
- 整组重复时，找出画面实际相同的部分。若每张都站着拨头发，可根据服装和场所换成停步、坐靠或整理袖口；若用户要求统一站姿，则变化朝向、景别或注意目标。

需要人工校准时，优先请用户指出一张不满意的成图及不满意部位，并提供喜欢的表情或姿势示例。示例可来自不同人物，按表现参考使用。只有需要更准确地复现当前人物的大幅表情或特殊角度时，才补对应的人物参考。
