# 整套穿搭与鞋履选择

根据主商品和用户指定的风格，完成能从头到脚成立的造型。用户只提供商品与脸图时，主动选择合适的搭配，将选择简短说明后执行。明确主商品、用户指定保留的单品与本次自行选择的搭配，参考图中的附带穿着仅按其实际职责使用。

## 先确定造型，再决定动作

从商品可见的版型、衣长、厚薄、垂坠、颜色和结构推导整套的方向。风格要由选中的单品、轮廓和比例共同实现。可以形成多种候选，结合当前用途选定一套后再扩展组图。

| 需要做出的选择 | 要落实的内容 |
|---|---|
| 主商品与叠穿 | 明确主商品怎样被看清，外搭的厚薄、长短和敞合如何与它配合。穿法应真实可行，展示商品衣长时保留可判断的下摆位置 |
| 下装 | 选定裤或裙的具体轮廓、腰位、长度和材质。判断它与上装之间的收放、长短及腰胯层次，裤装考虑大腿到裤口的连续走向，裙装考虑廓形与垂落 |
| 鞋袜 | 确定鞋的品类、鞋头形状与宽窄、鞋面高度、鞋底厚度、跟高和颜色。袜子或露肤按场景、季节与裤裙长度选择，裤脚和鞋口共同检查 |
| 配饰 | 帽、包、首饰按造型需要选用，颜色与材质有呼应，大小和位置服务于主商品。配饰与主体的风格关系应有明确依据 |
| 站坐变化 | 同一套搭配在站立与坐下时都应可执行。坐姿下裤料会在髋膝处变化，裙摆会与座面接触，据此选择姿势、座高与取景 |

提示词使用足够具体的可见描述。例如选择裤装时说明其垂坠、裤腿轮廓及与鞋面的长度关系，选择鞋时说明鞋楦和鞋底的体积。仅写“黑裤子”“黑皮鞋”“女鞋”很难限定预期造型。用“黑色乐福鞋”一类品类名称时，也要按本套风格确定鞋头、鞋面与鞋底形态。

商品图只露出上半身时，鞋履和完整下装由本次设计选定。将这些内容标明为搭配选择，并在生成输入中写清楚，参考依据只覆盖原图实际可见的部分。身体或姿势参考中的鞋服仅在用户指定或搭配选择有依据时沿用。

## 按整体比例检查选择

观察上装、下装和鞋履的视觉重量、长度与轮廓是否支持同一个造型目标。轻薄修身上装可以搭不同下装，重点在腰胯衔接、下装垂坠与鞋型是否形成预期效果。需要轻盈修长时，可通过合适的裤裙线条和较轻的鞋型表现，身体尺寸与腿长仍以已约定的身形为依据。需要有量感的造型时，厚底或宽鞋楦应与整套单品和用户风格相容。

当前用户反馈的米白打底衫案例中，生成方案自行选择了宽松直筒黑裤与黑色乐福鞋，成图出现较重的裤脚堆叠和宽厚鞋型，坐姿又强化了大腿与膝部的裤料体积。针对这套造型，应重新确定下装垂坠、长度与鞋口关系，并用更具体的鞋型描述控制下半身量感。用户对这次鞋型的否定用于修正该套造型，其他风格的鞋型按新的任务判断。

## 把搭配检查落实到出图

生成前用一两句写清选定的整套穿搭及其与主商品的关系。整组沿用具体选择，姿势变化时让衣料自然响应。优先检查组内能体现主要搭配的画面，在扩展其他图前修正已发现的造型问题。

验收时同时看商品是否准确、整套搭配是否符合预期，以及身体与布料是否成立。裤腿的异常拐折、膝部不合理鼓起、裤脚无依据地堆在鞋面，分别回到姿势、布料或长度选择修正。鞋形偏离选定造型时，明确修正鞋楦、鞋头、鞋底和裤鞋衔接。上半身近景对整套下装与鞋履的完成度提供的信息有限。
