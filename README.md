# 小红书生活化穿搭生图

`lifestyle-outfit-photo` 是一个 Codex Skill。提供模特脸图和服装商品图，就可以围绕商品的结构、颜色与穿着用途，策划一套完整搭配，再选择生活场景、拍摄角度、动作和表情。出图后逐张检查人物、商品、比例和实拍感。

## 安装

在 Codex 中发送下面的请求。

```text
使用 $skill-installer，从 https://github.com/mumu0214-chou/lifestyle-outfit-photo 安装 skills/lifestyle-outfit-photo。
```

## 使用

```text
使用 $lifestyle-outfit-photo。图 1 是模特脸图，图 2 是主推商品。
做一组 3 张小红书日常穿搭照片，分别展示整套比例、穿着状态和商品细节。
```

也可指定风格、场景、画幅或参考图，或者只要拍摄方案、提示词和成图复盘。需要固定身形时，随任务提供全身比例参考。生成图片需要当前环境支持图像生成和参考图输入。

入口是 [SKILL.md](skills/lifestyle-outfit-photo/SKILL.md)。[参考文档](skills/lifestyle-outfit-photo/references)包含整套搭配、姿势与表情、封面姿势示例和实拍感验收。
